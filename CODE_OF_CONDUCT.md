# Code of Conduct

## Our commitment

We want this project to be a welcoming, respectful space for everyone. Harassment, discrimination, personal attacks, and unwanted sexual attention are not acceptable.

## Expected behavior

- Be respectful and constructive.
- Welcome different viewpoints and experiences.
- Give and accept feedback thoughtfully.
- Focus discussions on improving the project.

## Enforcement

Report unacceptable behavior privately to the repository owner. Reports will be reviewed fairly and handled with appropriate confidentiality.
